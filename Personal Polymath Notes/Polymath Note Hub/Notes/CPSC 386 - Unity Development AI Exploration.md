## Lighting
* **Lights:** A game object that emits lights within the scene:
	* **Global**
	* **Spot**
	* **Point**
	* Unity defaults to a fully lit scene when no lights are present
* Color theory applies to lighting game objects, white is highly reflective, other colors may not be as pronounced.
* **Shadow Caster:** Details how shadows are drawn across an object
	* **Self Shadow**
	* **Cast Shadow**
	* **Cast And Self Shadow**

## Tile-Maps
* Children of a grid that details positioning of a game object in cubic or tillable form.
* **Tile Palate:** Contains grid objects that can be added or modified.
* **Tile map Rendered:** Draws the sprite 
* **Tile map Collider:**
	* **Composite Operations:** Details how collisions are drawn, separate segments, or unified segments.

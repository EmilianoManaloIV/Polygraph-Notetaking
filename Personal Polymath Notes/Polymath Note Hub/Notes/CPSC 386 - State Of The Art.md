## Unity
* Two-Three years version support, regardless of the new LTS version.
* Support for version upgradability with extensive documentation.
* High flexibility for cross platform support; requiring a single codebase to do it all: Nintendo Switch, Android XR, etc.
* Constant testing and support for legacy and "in-deployment" games.
* Utilizes "asset bundles" to minimize memory foot print.
* Fast shader compilation with high amounts of memory scalability.
* New Unity Core Standards system to guarantee usable and trusted third-party unity packages.
* More efficient shaders and directX12 compatibility.
* New sprite atlas analyzer to make more informed decisions on sprite based graphics systems.
* Optimized Refactor system for unity' animation system
* Higher scalability with Unity' 2D physics system.
* Auto configure graphics settings based on type of hardware your user is utilizing.
* Direct interaction with the RayTracing library.
* Shader graph has become more advanced, increasing flexibility.
* 3D to 2D composite light rendering has now been implemented. So that 3D objects can act like 2D objects at runtime.
* Multiplayer templates and unity building blocks; tried and tested solutions to fast track development.

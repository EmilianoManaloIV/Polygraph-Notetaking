**Activity Diagram**
* **Components:**
	* **Initialization**
	* **Conditional**
	* **Forks** (Concurrent/Parallel)
	* **Joins** (Two Or More Flows Combining To Create One Flow)
	* **Final State** (Activity Concludes/Terminates)
* Depicts how the operations or systems are executed.

**Activity**
* Activity: *What Activity Is Being Done*
* Often in rounded rectangle.
___
**Action**
* Represents the step in an activity
* Within the rounded rectangle
___
**Initial And Final Node**
* Initial Node: Represents where the flow starts
* Final Node: Represents the final flow in the activity
___
**Decision And Merge**
* "If else" that determines flow and is shaped as a diamond.
* Multiple incoming flows can be merged in an outgoing node.
___
**Fork And Join Node**
* Fork: beginning of a concurrent task
* Join: end of a concurrent task
___
**Partition & Swim Lane**
* Defines which "domain" each activity is available in.

___
**What Is It?**
* **DFD-0** the highest level of actions when it comes to a system.
* **DFD-1** more details in the system
* **DFD-2** technical details: individual diagrams of sub-systems, processes
* **DFD-3** shows *all* technical details
___
**Terminal**
* Can be a user, hardware, etc.
___
**Process**
* An operation that is done with the data; can be collected or manipulated.
___
**Data Flow**
* Showcases how the data moves from one place to another,
___
**Data Store**
* Represents an "archive" where data can be taken, stored, or referred to.
___
**Startups Vs Established Companies**
* Startups don't follow this, but, only do this if a system is established.

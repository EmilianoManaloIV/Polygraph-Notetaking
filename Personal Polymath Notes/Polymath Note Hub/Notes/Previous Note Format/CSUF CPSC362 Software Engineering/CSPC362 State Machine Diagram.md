___
* **State Machines**: Shows the "state" of the component and describes the behavior of the object.
* **State:** A current representation of what the object is.
* **Transition:** Represents how an object transforms from one state to another.
___
**Why Do We Use Them?**
* **Clarify Object Behavior**: Models the change due to external events.
___
**Components Of A State Machine Diagram**
* **States**
* **Transitions**
* **Events**
* **Initial State**
* **Final State**
___
**How To Create State Machine Diagram**
* **Step 1: Identify The Object**
* **Step 2: Identify Possible States**
* **Step 3: Identify Transitions**
* **Step 4: Define Events**
* **Step 5: Add Initial And Final States**

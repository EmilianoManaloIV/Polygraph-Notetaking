**What Is A Firewall?**
* Limits internet connection between the internal network (LAN) and the internet.
* Ifs priority is to monitor, filter, and audit traffic. Its like the coffee filter of the network world.
___
**Firewall Characteristics**
* Should let traffic go inbound and outbound on authorized traffic. 
* The firewall itself should be protected and shouldn't be able to be tampered with externally.
___
**Firewall Access Policy**
* Regulate the traffic due to the cybersecurity' policy. Addresses, protocols, applications, and content types.
* Should stem from risk assessment and security needs.
___
**Firewall Capabilities And Limits**
* Capabilities:
	* Defines a single choke point
	* Provides a location for monitoring security events
	* Convenient platform for several internet functions that are not security related.
	* Can serve as the platform for IPsec
* Limitations
	* Cannot protect against attacks bypassing firewall
	* May not protect fully internal threats
	* Improperly secured LAN
	* Laptop, PDA, or external devices can circumnavigate the firewall.
___
**Firewall Filter Characteristics**
* **IP address and protocol values**: Uses the IP address to limit the use of certain devices.
* **Application Protocol:** Relays and monitors the exchange of information for specific application protocols.
* **User Identity:** Used to secure inside users and secure authentication technology.
* **Network Identity:** the time of request, rate of requests, or other activity patterns.
___
**Types Of Firewalls**
* **Packet Filtering Firewall:** Applies rules to the data packets.
* **Stateful Inspection Firewall:** Creating a directory of outbound TCP connections
* **Application-Level Gateway:** Application proxy that relay' certain levels of traffic.
* **Circuit-Level Gateway:** Sets up two TCP connections, VPN example.
___
**DMZ**
* DMZ (demilitarized zone network)
* Segment important data from general data
___
**IPSEC**
* Built to ensure the security of data in the internet, internet protocol security, 
* Confidentiality and integrity of the data.
* **ESP:** Confidentiality and integrity
* **AH:** tampering protection
___
**Security Association**
* Agreement between two devices that secures a connection
___
**VPN**
* **Virtual Private Network:** Allows the safe transmission between sender and receiver by encrypting the data.
* IP address is hidden
___
**VPN Modes**
* **Tunnel Mode:** Site-to-site vpns, entrie packet
* **Transport Mode:** remote access VPNs, encrypts just the payload.

**Malware Terminology**
* **Adware:** Attacks availability and often disrupts the function of a device.
* **Backdoor:** Passes authentication/security and potentially lets other programs in.
* **Downloaders:** Downloads malicious codes.
* **Trojan Horse:** Download malicious code as it looks legitimate.
* **Virus:** Malware that if executed infects other devices within the network.
* **Worm:** Program that runs independently and infects other devices and doesn't need execution.
* **Zombie/Bot:** A program that attacks other machines in the LAN
* **Flooders:** Denies availability at a system through network overloads.
* **Keyloggers:** Records data off of what values are set in the keyboard.
* **Logic Bomb:** A program that stays dormant until a given event occurs.
* **Macro Virus:** Infects smaller applications by utilizing generic file types that are found in most situations.
* **Rootkit:** Attacks the computer to ger admin permissions.
* **Spammer Programs:** Floods your email so annoy you.
* **Spyware:** A program that collects and transmits data to somewhere else.

**Viruses**
* Piece of software that infects programs and its often modified, then replicates other machines within the network.
* It needs to be executed by a user or host program.
* It often addresses hardware, permissions, and software.
* **Components**
	* Infection Mechanism: How the virus spreads
	* Trigger: Conditions that trigger the payload
	* Payload: What the virus does other than the infection mechanism
* **Phases**
	* Dormant Phase
	* Triggering Phase
	* Propagation Phase
	* Execution Phase
* **Classification By Target**
	* Boot Sector Infector
	* File Infector
	* Macro Virus
	* Multipartite Virus (Used a combination of targets)
* **Classification By Concealment Strategy**
	* Encrypted Virus
	* Stealth Virus
	* Polymorphic Virus
	* Metamorphic Virus
___

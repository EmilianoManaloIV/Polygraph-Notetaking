**What Is Linux?**
* Linux is open source, thus, we have many security items that need to be addressed. 
___
**Linux Security Model**
* The **Root** contains all the permissions that controls the entire system, this is the main target to get exclusive admin permissions.
* DAC (Discretionary Access Control), often set permissions such as read, write, & execute.
* Linux prioritizes usability above all else, rather then security.

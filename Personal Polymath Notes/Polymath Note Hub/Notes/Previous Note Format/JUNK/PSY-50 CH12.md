**Factorial Designs**
* Each IV has at least two levels
* IVs are crossed with each other, crating all possible combination of the levels
* IVs can be participant variables or manipulated variables
* IVs can be within groups variables or independent-groups variables
___
**Spreading Interaction:** Alligator mouth (A relationship between one variable and not the other)
* Two conditions->two groups->four possible outcomes
* Main affect occurring?
* Is there a difference between groups?
___
**Factorial Designs**
* Main Effect: isolated effect of each IV
* Interaction: the effect of one independent variable depends on the other independent variable
* Interaction: difference in differences
___
**Independent-Groups, Within Groups, And Mixed Designs**
* IVs can be manipulated as within-groups or between groups
* Implications for numbers of participants 
* Implications for statistical testing
